# Operations Built for Growth — Knowledge Extraction

This folder preserves the practitioner knowledge extracted during the 2026-08-08 interview that followed the supplied **Operations Built for Growth** interview brief.

## Important status

These files are **knowledge-preservation artifacts, not ratified Northlight doctrine**.

They intentionally preserve:
- Elizabeth's raw conceptual distinctions;
- lived observations;
- examples from her work;
- working metaphors;
- candidate principles;
- unresolved questions;
- claims that may require external research or validation.

The conceptual architecture and foundational framework document have **not yet been finalized**.

## What is deliberately not done here

This session does **not**:
- lock the framework into a final five-principle model;
- present the Market-Aware COO as an established industry category;
- treat Elizabeth's observations as universally validated research findings;
- replace existing ratified Northlight `values.md`, `principles.md`, or `methods.md`.

## Core working idea

> Operations is the backbone of an organization: the infrastructure and nervous system through which people, information, decisions, commitments, and learning move.

The emerging proposition is that operations should be built not merely for the organization that exists today, but for what the organization is becoming — while retaining the ability to respond intelligently when reality changes.

## Current working cycle

**Awareness → Sense → Build → Connect → Learn → upward spiral**

This remains a working architecture, not a final framework.

## Files

- `interview-kernels.md` — preserved conceptual kernels and formulations from the interview.
- `observations.md` — practitioner observations and recurring patterns.
- `examples.md` — concrete examples that ground the concepts.
- `working-concepts.md` — candidate conceptual structure, kept deliberately provisional.
- `validation-questions.md` — claims and ideas that should be researched before being presented as general theory.
- `provenance.md` — source and status notes.
