## Key Claims

- Northlight Vault is locally-installed: no registration, no account, no user data reported back — the app does not know who installed it, which cloud accounts were connected, or what files were viewed
- Northlight uses only Plausible Analytics (aggregate, anonymised) on the website — no individual profiles, no cross-site tracking; Aurora Brief collects first name and email only, nothing more
- Privacy-first is a design principle, not a compliance checkbox: the starting question is "what do we actually need?" not "what do we need to be compliant?" — PIPEDA tells you how to handle data you've decided to collect; this question is about whether to collect it at all
- Practical design rule: collect only what you can explain, specifically, what you'll do with; over-collection stops being useful and still violates privacy — when you have everything, you can't find anything
