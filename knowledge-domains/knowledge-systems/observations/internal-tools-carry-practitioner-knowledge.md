# Internal tools carry practitioner knowledge

## Observation

The MCP skills article explains that tools built for internal use encode real workflow decisions before they become products.

## Interpretation

Purpose-built tools can preserve practitioner judgment because they embody repeated choices about process, friction, and useful output.
