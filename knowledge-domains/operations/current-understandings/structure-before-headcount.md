# Structure Before Headcount

Operational problems are rarely solved by adding people. A new hire lands in the same system as everyone else — if the bottleneck is structural, the hire inherits it. Decision ownership, capacity visibility, and clear process must exist before new roles can produce the expected result.

Fractional leadership is a useful diagnostic: if a part-time operator can run a function effectively, the function is well-structured. If they cannot, the problem is not the hours — it is the operating conditions.

This understanding should continue to accumulate supporting evidence.
